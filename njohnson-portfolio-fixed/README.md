# NJ Portfolio

Personal game development portfolio for Nick Johnson.

## Local preview

No build step is required.

Open `index.html` directly in a browser, or use a simple local server:

```bash
python -m http.server
```

Then visit `http://localhost:8000`.

## GitHub Pages

For a GitHub user site, the repository should be:

`Famouspizza23.github.io`

GitHub Pages can publish the repository directly from the `main` branch.

## Replacing placeholder media

The current version intentionally uses CSS placeholders so the site works immediately.

On each project page, replace the placeholder blocks with:
- screenshots
- GIFs
- trailers
- development videos
- concept art
- diagrams

The content is deliberately organized as case studies so additional media can be added without changing the overall layout.
